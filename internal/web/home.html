{{if eq .Name "blygd"}}This host runs{{else}}{{.Name}} runs{{end}} blygd, a Blygger studio: one server that publishes blygs, reads other people's, keeps private hoppers, and handles Webmentions.

Blygger is a decentralized public writing medium built on static files and RSS. Each author's blyg is mounted at its own path on this host. There is no directory of them here: you reach a blyg from its author's link.

Have an invite? Make your blyg.
