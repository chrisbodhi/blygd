# Deploys

What is live at `eurypos.com`, and at `blyg.newschematic.org`, the public
host until 2026-11-20, whose origins are served there for good. Newest
first. Add a row each time you ship (see "Upgrading" in
[DEPLOY.md](DEPLOY.md)), or change the public host. The commit is the one
the binary was built from, and the SHA-256 is of the file installed at
`/usr/local/bin/blygd`, so `sha256sum` on the server says whether it is
this one. Migrations are the schema version the database was at after the
restart (`blygd migrate status`).
